Пересчитано 23.11 текущим правилом по сохранённым контекстам, без новых вызовов: по всем строкам таблицы 0.87 (до исправления правила, при прогонах, было 0.22). Разбор: низкое значение было артефактом сопоставления, не галлюцинациями. Из верных ответов с «негодной» цитатой по старому правилу 73% — только форма (модель пишет кавычки „…“ вместо «…», добавляет «п. 3.17:» и номера пунктов), 22% — две дословные цитаты в одной строке через «;» или « / », ≈3% — настоящий пересказ, ещё ≈2% — куски без разделителя. Правило остаётся дословным: слова и числа не нормализуются, пересказ или изменённое число по-прежнему не засчитываются.
